about=G.S.I. stands for Grid Sheet Importer. The plugin fetches the basic items of the Fundamental Geospatial Data (基盤地図情報 基本項目) of the Geospatial Information Authority of Japan (GSI) and selected features of the GSI optimized vector tiles (a trial release), sheet by sheet (2nd-level meshes, about 10 km square), and stores them in a single GeoPackage instead of many shapefiles. The latest data date and the stored state are shown for each mesh in a table and as colours on the map, and data already stored and up to date is not downloaded again. Fetching goes mesh by mesh, so stopping never leaves a half-imported mesh. The layers are placed in the Layers panel in groups, for the visible meshes or for all stored areas. A GSI Tiles (pale map) preview helps to choose the area. English and Japanese user interface. Downloading the Fundamental Geospatial Data requires a free user account for the GSI download service (the optimized vector tiles need no login); the ID and password can be saved in the QGIS settings (not encrypted). Japan only. Requires GDAL 3.8 or later for the vector tiles (PMTiles driver) and an internet connection. This plugin is an independent work and is not affiliated with or endorsed by GSI. Use of the fetched data must follow the GSI terms of use and the Survey Act of Japan (attribution, noting any processing, and an application where required).
